Дата проверки предложений: 11 октября 2026 года. География старта — Москва и Московская область; производство Dolwood — городской округ Щёлково. Продукция — только бук.

Рекомендация: первым запустить привлечение покупателей готовой буковой доски, если есть свободные к продаже партии. Одновременно подготовить предложение по серийным мебельным деталям и декору с покраской. Доска подходит для быстрой проверки онлайн-продаж; заготовки дают больше возможностей построить отношения вокруг конкретной серии клиента. Повышенная прибыльность заготовок — гипотеза, которую нужно проверить по затратам и загрузке оборудования.

Основание выбора — публичные предложения семи конкурентов, условия Dolwood и сложность первой сделки. Это исследование предложения, а не измерение размера рынка: частотность запросов, рекламные ставки, фактические продажи конкурентов и себестоимость Dolwood не установлены. Цены ниже — опубликованные ориентиры, а не полученные коммерческие предложения. Объявления с устаревшими низкими ценами не использованы как текущий ценовой ориентир.

Для заготовок лучше начинать с узкой серии, которую производство уже уверенно делает: например, ножки и опоры для мягкой мебели либо подлокотники и царги. Выбор конкретного семейства зависит от существующих заказов, себестоимости и оснащения. Начинать с обещания изготовить любой сложный декор рискованно при отсутствии ЧПУ.

### Первая функция для доски

Начать с паспорта конкретного пакета и показа партии до оплаты. Фотографии у конкурентов уже есть, поэтому ценность должна быть в связанном наборе данных: номер партии → состав → влажность → согласованные критерии приёмки → отгрузочные документы. Сначала это может быть один PDF и переписка с менеджером.

На сайте показывать один настоящий пример паспорта, несколько актуальных партий и кнопку запроса конкретного пакета. Не обозначать весь склад доступным без системы обновления остатков.

### Основная функция для заготовок

Проверить предложение «утверждённая деталь для повторных заказов»: согласовали образец, геометрию и отделку один раз; следующие партии запускаются по коду после проверки цены и срока. Усилить комплектами под конкретную мебель и графиком отгрузок.

Отдельные элементы уже встречаются у конкурентов. Потенциальное отличие — качество исполнения всего процесса для узкой группы заказчиков, а не доказанная уникальность идеи. На первом этапе достаточно архивной папки, физического эталона и таблицы заказов; личный кабинет можно делать после подтверждённых повторных продаж.

## План проверки на первые тридцать дней

1. **Первая неделя:** зафиксировать свободные партии доски и мощности под детали; снять фото; собрать спецификации; рассчитать вклад заказа в покрытие расходов. Отобрать несколько выполненных деталей для отдельной страницы.
2. **Вторая неделя:** подготовить разные страницы и обращения для доски и заготовок. Доска — наличие и запрос партии. Заготовки — примеры, ограничения обработки, запрос по чертежу и условия образца. Настроить учёт источников заявок.
3. **Третья и четвёртая недели:** провести небольшой тест двух отдельных групп поисковых запросов с контролем расходов и загрузки. Для доски стартовать с Москвы и области; по заготовкам проверить географию, в которой доставка не уничтожает экономику заказа. Не смешивать запросы частных покупателей одной ножки и серийных заказчиков.
4. **После тридцати дней:** сравнить оплаченные заказы и качество незакрытых расчётов. Если цикл сделки по деталям длиннее, не считать отсутствие оплат за месяц доказательством отсутствия спроса.

Примеры запросов для проверки: «буковая доска оптом», «бук камерной сушки 30 мм», «буковая доска 50 мм Москва»; отдельно «ножки из бука оптом», «мебельные детали по чертежам», «подлокотники из бука на заказ». Это начальные гипотезы семантики, а не подтверждённые частотности. Перед покупкой рекламы проверить формулировки и географию в Вордстате.

Первые показатели: подходящие запросы, выданные расчёты, оплаченные заказы, затраты на привлечение покупателя, вклад заказа в покрытие расходов, срок получения оплаты, часы оборудования и процент переделок. Клик по мессенджеру считать промежуточным действием; квалифицированная заявка содержит продукт, параметры, объём и срок. ## Как принять решение по экономике

Для каждого направления считать вклад заказа: выручка минус сырьё, сушка и энергия, труд, расходные материалы, переналадка, покраска, упаковка, оплачиваемая вами логистика, ожидаемые переделки и привлечение клиента. Использовать сопоставимую базу учёта налогов. Для собственного бука учитывать внутреннюю стоимость сырья, чтобы не завышать прибыль деталей.

Для доски дополнительно учитывать стоимость содержания запаса и потери при сортировке. Для заготовок — стоимость согласований и время на образец. Сравнивать не только процент наценки, но и вклад на час самого загруженного оборудования. Повторные закупки учитывать по фактической истории; неподтверждённую будущую выручку не использовать для оправдания убыточной первой сделки.

До расходов нужны пять внутренних показателей: вклад в покрытие расходов по кубометру доски; вклад и трудоёмкость типовой партии деталей; свободный складской объём; свободные часы по операциям; история повторных заказов действующих партнёров. Если заготовки выигрывают по вкладу на ограничивающий ресурс и есть свободная мощность, им следует дать приоритет даже при меньшем числе заявок.
